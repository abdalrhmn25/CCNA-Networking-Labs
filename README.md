## About This Repository

Welcome to my CCNA Networking Labs Portfolio.

This repository documents my practical networking journey through Cisco Packet Tracer, focusing on network configuration, routing, switching, network security, and troubleshooting.

The goal is to strengthen my hands-on networking skills and build practical experience through real-world network scenarios.

## Topics Covered

- Network Fundamentals
- IPv4 Addressing and Subnetting
- VLANs and Trunking
- Inter-VLAN Routing
- STP and EtherChannel
- Static and Dynamic Routing
- OSPF and RIP
- ACLs and Network Security
- DHCP, DNS, and NAT
- IPv6
- Network Troubleshooting
